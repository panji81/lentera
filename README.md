Lentera — Penjaga Cahaya: you are a small lantern spirit flying through a twilight valley. Gather light orbs, dodge shadow wisps, chain combos, and keep your light alive. A vanilla-JS canvas game with no libraries and no network requests — score, combo multiplier, lives, levels, a light meter, burst, pause, restart, and synth sound.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. (Or open `game/index.html` directly — it runs offline.)
